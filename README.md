# Text Generation with Markov Chains

## Overview
This project implements a simple text generation algorithm using Markov Chains in Python. The model learns word transition patterns from a given text and generates new text by predicting the next word based on previous words.

## Features
- Builds a Markov Chain from input text
- Generates random text sequences
- Demonstrates basic Natural Language Processing (NLP) concepts
- Easy to understand and implement

## Technologies Used
- Python
- Random Module

## How It Works
1. Read and process the input text.
2. Create a dictionary of word transitions.
3. Randomly select a starting word.
4. Generate new text by choosing the next word based on learned transitions.

## Sample Output
Generated Text:
Artificial Intelligence helps in automation. Automation improves productivity and efficiency.
